# LiYi's Channel

李毅的个人网站，记录分享、手记与摄影。在线访问：[liyizju.com](https://liyizju.com/)。

## 网站内容

| 栏目 | 地址 | 内容 |
| --- | --- | --- |
| 主页 | `/` | 最近更新、日历与月相书签 |
| 分享 | `/sharing/` | 文章与资料分享 |
| 手记 | `/notes/` | 日常记录与随笔 |
| 摄影 | `/photography/` | 照片与拍摄记录 |

银河背景搭配轻微视差与鼠标追随粒子，栏目沿半圆轨道切换。主页采用可拖动的大头针卡纸，其他栏目通过 3D 循环卡片浏览，支持鼠标、键盘与触屏操作。

- 全站搜索：按标题、描述和标签检索，也可按栏目筛选；支持 `Ctrl / ⌘ + K`。
- 最近更新：自动汇集三个内容栏目的最新条目。
- 日历与月相：切换月份、查看今天，展示近似月相与北京时间农历。
- 摄影浏览：在全屏灯箱中查看照片，支持左右切换与滑动。

没有内容时保留空白卡片；发布后，卡片、搜索与最近更新会自动同步。手机端个人信息位于内容下方。

## 本地运行

使用 **Astro + React + Three.js**，需要 **Node.js ≥ 22.23.4**。

```sh
npm ci
npm run dev
```

本地地址以终端输出为准。检查并预览发布版本：

```sh
npm run check
npm run build
npm run preview
```

添加文章与照片见 [内容维护指南](CONTENT.md)。推送到 `main` 后，GitHub Actions 会自动构建并部署到 GitHub Pages。
